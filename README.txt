# 風量計算 PWA（排煙風量画面改修版）

## iPad・iPhoneでの利用
1. このフォルダー内のファイル一式をGitHub PagesなどでHTTPS公開します。
2. Safariで公開URLを開きます。
3. 共有メニューから「ホーム画面に追加」を選ぶと、アプリのように起動できます。

## 今回の排煙風量画面
- サイズ一覧選択時は幅・高さの入力欄を非表示にします。
- 幅・高さ入力または有効開口面積の直接入力を選べます。
- 有効開口面積と有効開口率は、入力された値をもとに計算します。外形面積を自動的に有効開口面積とはみなしません。
- 実測風量はm³/minとm³/hを両方表示します。
- 詳細計算内で設計風量、設計風速の自動計算、床面積、床面積1㎡当たりの必要風量、排煙必要風量、実測／必要の比較を扱います。
- 履歴は利用中のブラウザーのローカル保存領域に保存します。

PWAはSafariのfile://表示ではなく、HTTPSで公開して利用してください。
